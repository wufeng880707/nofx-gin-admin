# XTrading 前端字体与字号规范

## 1. 目标

本规范用于统一 XTrading Console 的管理页面、交易终端、策略工作室和数据分析页面。字号表达信息层级，不跟随视口宽度缩放；主题切换只改变颜色，不改变字号、行高和组件尺寸。

## 2. 字号层级

| 语义 | 字号 | 行高 | 典型场景 |
| --- | ---: | ---: | --- |
| 辅助说明 `caption` | 12px | 20px | 表格补充信息、时间、字段说明、Prompt 与日志 |
| 正文 `body` | 14px | 22px | 表单、表格、菜单、按钮和普通正文 |
| 强调正文 `body-lg` | 16px | 24px | 卡片标题、重要数值、紧凑区块标题 |
| 中标题 `title-md` | 20px | 28px | 页面标题、主工具标题 |
| 大标题 `title-lg` | 24px | 32px | 独立分析页的一级标题，管理页谨慎使用 |
| 核心指标 `kpi` | 28px | 36px | 总资产、净收益等首屏核心数据；不用于表单或普通卡片 |

禁止事项：

- 禁止使用 `vw`、`clamp()` 等方式按视口动态缩放字号。
- 禁止负字间距；全局 `letter-spacing` 保持 `0`。
- 禁止在紧凑面板中使用 24px 以上标题。
- 禁止为了容纳文本持续缩小字号；应优先换行、省略或调整布局。

## 3. Ant Design Token 映射

| Ant Design Token | XTrading 值 |
| --- | ---: |
| `fontSizeSM` | 12 |
| `fontSize` | 14 |
| `fontSizeLG` | 16 |
| `fontSizeXL` | 20 |
| `fontSizeHeading5` | 16 |
| `fontSizeHeading4` | 18 |
| `fontSizeHeading3` | 20 |
| `fontSizeHeading2` | 24 |
| `fontSizeHeading1` | 30 |

全局实现位于 `web/src/app.tsx` 的 `ConfigProvider`。页面局部样式必须优先引用 `web/src/global.less` 中的 `--font-size-*` 和 `--line-height-*` 语义变量，不重复定义无语义的字号。

## 4. 页面规则

### 4.1 管理列表与表单

- 页面标题使用 20px，区块标题使用 16px。
- 表格、筛选器、表单标签、按钮和菜单使用 14px。
- 时间、ID、说明、校验提示使用 12px。
- 表格数据列保持单行时，应使用省略和 Tooltip，不允许压缩到 12px 以下。

### 4.2 Dashboard 与分析页

- 总资产、净收益等主 KPI 可使用 28px。
- 次级指标使用 16px 或 20px，不与主 KPI 争夺层级。
- 图表坐标、图例和注释使用 12px；图表标题使用 16px。
- 盈亏、价格、数量和百分比启用 `tabular-nums`，避免刷新时数字宽度跳动。

### 4.3 策略工作室与交易终端

- 工作区页面标题使用 20px，配置区标题使用 16px。
- Prompt、模型输出、运行日志使用 12px 等宽字体，正文行高不低于 1.7。
- 风控值、Token 估算和实时行情数值使用等宽数字特性。
- 控件有稳定高度，标签换行不得推动相邻工具栏或图表重新布局。

## 5. 响应式规则

- 桌面与移动端保持相同字号层级，通过网格列数、换行和区域堆叠适配。
- 560px 以下，配置网格改为单列；不缩小正文和按钮字号。
- 长英文单词、交易对和模型名需要 `overflow-wrap`、省略或 Tooltip，不能溢出容器。
